Certifier (F5)

Findings that change the plan or the manual

  • Decision: option E adopted. The coherence rule now accepts a true fault whose signature has cosine above 0.95 with a competitor only if it is still at least 5 sigma from the best-fitting competitor at its true magnitude, and mid-episode drift is cut (plan cut list item 1): the hard tier keeps 3 physical and 2 sensor faults without drift. Discard rates (easy / medium / hard): 8 / 20 / 31%, against 14 / 37 / 57% for the plan's cosine rule on the same draws. Both rules use the full probe menu, which costs more than B, so they are necessary conditions, not proof of solvability within budget; the oracle (Step 5) checks sufficiency. The drift code stays in faults.py with its tests, ready to return if time allows.
  • F1 deviation: pipe counts. The plan's ranges cannot all hold at once: easy plants have 6-8 junctions and 2-3 outlets, which leaves 3-8 pipes once 2-4 links are valves, while hard plants reach 15. Measured: easy 3-8; medium 6-12; hard 9-15 pipes. Counting all links (pipes, valves and pumps) would be the natural reading if the plan meant network size.
  • Generator first draws. Trees are now built with at most the tier's maximum number of leaves, so 99.9% of seeds need no internal redraw (plan: at least 95%).
  • Static test with a leak is not "flows read zero". When the pumps stop, the tanks backfeed the leak. Flow meters on that path read up to 25 sigma (median 10) at an 8% leak and up to 6.3 sigma at 2%. This is a leak signature for the manual. Pressure sag reaches 1.11 sigma at 8%, above the plan's 0.5 sigma assumption (F10); at 2% it is 0.07 sigma.
  • Open decision: stuck sensors read an exact constant. The plan says "the reading is constant", so two reads that match bit for bit identify a stuck sensor with certainty for 2 budget units, and each read is a noise-free measurement. Alternative: stuck value plus normal noise, so detection needs an experiment that should move it.
  • Open decision: every physical fault must degrade the KPI by at least 5%. Plan section 4.2 asks for "at least one". It keeps every fault worth repairing, but it excludes suction-side leaks and most loop-chord fouling (fouling 82%, leaks 83% of pairs eligible; pump wear and stuck valves 100%).
  • Fixed: low-speed steps deadheaded healthy pumps. At s = 0.5, 72% of healthy plants could not beat the static lift, which made a speed step a cheap static test (plan decision 12). The speed step is now limited to [0.7, 1.2], and the generator guarantees a healthy pump overcomes the lift at 0.7 with 2 m to spare. Worn pumps at low speed can still deadhead; that is a real wear signature, and the KPI floors delivered flow so it stays finite.
  • Fixed after independent review: the stuck-valve check now tests both valve-step openings (a valve stuck at 0.3 looked healthy under a 0.3 command); the truth record has an onset field; the generator redraws heads when a small tree has no valid loop chord (the independent F1 test caught 3 in 1000 medium seeds). An independent code review then found that in two-pump plants a single pump stepped to 0.7 could still deadhead against the header held up by the other pump (149 of 622 plants); the lift is now measured against the header and 0 of 1,244 single-pump steps deadhead. The review cross-checked the certifier against its own implementation of spec section 10 and found no bugs. When every pump is stopped the solver now starts from the known static solution.
  • The CRB rule is weak with known support. Accepted instances need a median of 2 / 7.0 / 12.0 budget units (easy / medium / hard) to pin magnitudes to 10%. Coherence does almost all the rejecting. Real difficulty sits in finding the support, which the oracle (Step 5) will measure.
  • A stopped pump leaks about 1e-5 L/s through the smoothed check valve, three orders below the smallest flow sigma (0.01 L/s). Static-test checks use an absolute tolerance.
  • Sensor placement rule added. Every junction joining exactly two pipes or valves in series now carries a pressure sensor. Without it, fouling on either side is truly indistinguishable (cosine exactly 1.0).
