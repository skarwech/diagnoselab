Findings

  • F21 fails, consistently with Step 6. On 60 frozen test seeds x 3 runs, Kimi K3.1 Pro scores 0.858 normalised (easy 0.96, medium 0.81, hard 0.81). The oracle's lead is 0.142 (95% CI 0.10 to 0.19): real, but under the plan's 0.25. The runs agree closely (sd 0.019), so this is not noise.
  • The measurable weakness is budget, not knowledge. The agent reaches about the same information about the true faults as the oracle, but spends 35-40% more to get it (28 / 34 / 36 units vs 21 / 24 / 26). Per budget unit it gathers 0.40 / 0.83 / 1.25 nats against the oracle's 0.55 / 1.17 / 1.71, and its probe choices beat random probes at the same spend in only 35-38% of episodes. Its dominant habit is reading 10-27 sensors one by one before the first experiment (flagged in 90% of easy, 62% of medium and 42% of hard episodes).
  • Other failure hypotheses barely occur. It always runs the static test (no-disambiguation 0%), rarely misses a lying sensor (2 of 120 on hard, 4 of 60 on medium) and almost never anchors (1 flagged episode). The automated budget-myopia flag matched an independent blind labeller on all 12 cases (kappa 1.0); anchoring had one case per rater on different episodes (kappa -0.05), too rare to validate; the other two flags never fired in the sample (undefined kappa, perfect agreement).
  • Friction stays negligible: 47 rejected calls of 11,303 (0.42%), no invalid submits. Two episodes ended without a submit (the agent stopped after 34 valid calls; scored 0), and two opencode processes exited with an error after a completed submit (scores stand).
  • Hint ablation: the habit goes, the score does not move. One added instruction line ("single sensor reads are the least informative probes per budget unit; run the static test and a speed step first") on the 40 medium and hard test seeds, one run each, compared with the same seeds' three unhinted runs. The agent stopped reading sensors before experimenting (0 reads first vs 10; myopia flagged 0% vs 52%) and spent less (29.5 vs 35.1 units), but its score moved only +0.017 (95% CI -0.07 to +0.10). F22's hint condition (+0.15) fails. Budget myopia is a real habit but a cheap one: efficiency is 20% of the reward, and the agent's lost points come from occasional misdiagnoses. The first attempt lost 30 episodes to a revoked API key; those were rerun with a new key and the failed attempts excluded (infrastructure, the agent never ran).
  • The oracle and baselines on the same seeds: the oracle through Harbor equals its cache on all 60 test tasks; evidence-free baselines stay at or below 0.08; the lazy heuristic matches the oracle on easy (1.00) and scores 0.51 / 0.47 on medium / hard.
  • Cost of this step: about 99M input tokens (mostly cached) and 1.17M output for 180 episodes. Check the Verda console against your $50 cap before any further runs.
